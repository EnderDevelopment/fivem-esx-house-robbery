# Heist House Robbery

Heist House Robbery is a FiveM resource that allows players to engage in house robberies with various mechanics, including lockpicking, sound level monitoring, and cabinet searching. The resource includes five different house robbery variations, each with unique settings for lockpicking time, sound level increase, and cabinet search time. Players can manually set locations for house robberies using the `/addrobberylocation` command.

## Install

1. Download the resource from the GitHub repository.
2. Extract the files into your FiveM server's `resources` directory.
3. Add `ensure HeistHouseRobbery` to your server.cfg file.

## Use

1. Start the resource on your FiveM server.
2. Players can use the `/addrobberylocation` command to set locations for house robberies.
3. Players can interact with the robbery locations to start the robbery process.
4. The lockpicking minigame will appear, and players need to complete it to proceed.
5. The sound level bar will rise as the player moves, and if it reaches the maximum level, the robbery will be detected.
6. Players can search cabinets to find items, using the same minigame mechanic as the lockpicking.
